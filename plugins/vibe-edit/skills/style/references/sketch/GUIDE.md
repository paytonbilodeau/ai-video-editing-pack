# Sketch stills

Read the complete [style specification](references/payton-sketch-style-spec.md). It contains the exact still and motion lock blocks, six composition modes, palettes, line/fill treatment and acceptance rubric. The [workflow guide](references/style-guide.md) preserves detailed prompts and metaphor choices; the canonical specification wins if an older compatibility example conflicts.

1. Read the user's idea, script or authorized image. Write the one physical relationship the viewer should understand in two seconds.
2. Choose character action, prop close-up, scale contrast, two-panel cause/effect, short title punctuation, or a necessary simple diagram. One metaphor, one dominant action, one focal object.
3. Use an available native image generator. Make the exact short words and necessary marks part of the original scene. Do not invoke a paid fallback automatically.
4. Apply the full Sketch style lock. Use the customer's own approved character sheet when a person is necessary; otherwise a generic person or no person. Keep 5–15% visible underdrawing and 70–80% quiet field as taste guides, not pixel quotas.
5. Inspect the actual PNG at full and phone size: causal meaning, hand interaction, roughness, negative space, spelling, consistent identity and stable logo geometry. Fix the image natively before motion.
6. Save the lossless original to a new output name. Keep prompt, source rights and a useful short correction receipt beside the project, never inside a global secret store. Keep useful previous versions.

Batch requests get one clear thesis and a varied composition per useful image; quick requests need one image; restyling preserves the supplied scene's meaning. Do not invent a new thesis to fill a layout.

For animation, continue to [Sketch motion](../sketch-motion/GUIDE.md). The optional paid Kie adapter is included at the style skill's `tools/optional/generate_hand_drawn.py`; it requires current provider checks and explicit approval. Its presence does not provide a key, credits or generation permission. A prompt plan is not a generated result.
