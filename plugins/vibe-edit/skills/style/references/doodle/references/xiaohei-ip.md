# Xiaohei character

Xiaohei is Ian's recurring visual character. Include one in each illustration unless the user explicitly changes the brief.

Draw a small solid-black creature with white dot eyes, tiny thin legs, occasional thin arms, and a slightly uneven outline. Its body can resemble a bean, cylinder, black box, funnel, shadow, opening, or dark part inside a machine. Keep its expression blank, calm, and serious.

It is a deadpan worker doing something slightly absurd but causally useful. It can carry, pull, sort, repair, weigh, stitch, guard, open, receive, or label. Choose the action because it explains the concept. Do not make it foolish, excessively cute, glossy, elaborately dressed, or expressive like an emoji.

If removing Xiaohei leaves the metaphor completely unchanged, it is decoration. Rewrite the scene so its action explains the idea. The character must not overpower the explanation.
