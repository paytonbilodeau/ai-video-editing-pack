# Illustration QA

Inspect the actual image at full and phone size. Self-review is not independent user comprehension testing.

- Does the picture accurately explain one source-grounded idea?
- Does Xiaohei perform the action that explains it?
- Is the metaphor fresh rather than a copy of a bundled example?
- Are the actual dimensions 16:9 and the background clean white?
- Is the subject sparse, with ample whitespace?
- Are every label's spelling, language, and meaning correct and readable?
- Is orange used for main movement, red for emphasis/problems/results, and blue for secondary notes or feedback?
- Are there no unwanted titles, structure names, long paragraphs, fabricated UI, or distorted brand marks?
- Does it look like a physical hand-drawn scene instead of a slide or formal flowchart?

If bland, put the character in charge of the causal action. If crowded, remove nodes and reduce labels to three to five. If cute, emphasize a blank serious expression. If slide-like, remove titles, frames, grids, and excess arrows. If too similar to an old example, change both main object and character action. For spelling mistakes, edit locally; for many mistakes, regenerate with fewer labels.

Normally allow two focused correction rounds. Report unresolved faults rather than treating a generated file as proof of quality. Preserve originals, verify delivered files and dimensions, and report the location.
