# Style and motion from a brief

Use the style and reference fields in
[PROJECT INTAKE](<../../edit/templates/core/PROJECT INTAKE.md>). Describe what each
authorized reference contributes: composition, timing, typography, movement,
or material. Do not copy a private recipe, exact frame, trademarked mark, or
unlicensed asset. State what new visual helps the viewer understand.
See [MOTION AND LUTS](<MOTION AND LUTS.md>) for optional
Remotion, Hyperframes and JavaScript animation setup, alpha hand-off, the behind-the-person method in
each editor, reference translation and output checks. Graphic entrance, hold
and exit timing and caption rules are in
[EDITING CRAFT NUMBERS](<../../edit/references/core/EDITING CRAFT NUMBERS.md>).

Offer optional motion preparation during setup using
[MOTION TOOL SETUP](<MOTION TOOL SETUP.md>). Explain the useful
choice in plain language, then perform the approved setup. Reuse working tools,
styles and assets. The person can add one route, several routes, or defer setup.

Choose each scene's route by its job: native editor controls for a simple title
or footage-linked mask; Remotion for reusable React compositions; HyperFrames
for HTML/CSS scenes; [JavaScript animation](<../../javascript-animation/references/CORE GUIDE.md>)
for procedural diagrams and its supplied public drawing kits. They can be used
together through rendered layers, and the JavaScript kit has a Remotion adapter.
Do not force a simple title test before a task that clearly needs another route.

Keep one useful idea per visual beat. Show what changed and why it matters.
Group related objects, keep the meaning readable during motion, and allow a
settled reading hold. Use the person's style rather than importing a creator's
brand, private visual recipe or arbitrary frequency of zooms and effects.

Before a long sequence, render a representative short sample and inspect it in
the receiving editor. Check frame rate, transparency, entrance, settled hold,
exit, captions and sound. Apply routine corrections within the authorized edit;
ask only when a consequential choice remains outside it.

Review the moving composite with sound, not just a still. Record the visual
purpose and accepted version in
[EDIT PLAN AND REVIEW](<../../edit/templates/core/EDIT PLAN AND REVIEW.md>).
Return to [review and delivery](../../edit/references/core/review-delivery.md).
