# Show the action

At each important verb, make a visible consequence: remove a repeated point,
select a useful passage, rearrange a supporting detail or correct the actual
word. A slider called judgment does not demonstrate judgment unless moving it
changes something relevant. Use the narration's nouns and actions.

Keep authentic media when it serves the claim. Do not invent quotations, authors,
numbers or results to make a graphic impressive. A diagram can be conceptual
without pretending to be measured. Vary scale and density where meaning warrants
it; do not force every explanation into a headline and two identical cards.

Compare the actual before/after interval and record the remaining judgment.
A clean render is necessary, but does not establish creative acceptance.
