# Keep context while directing attention

Retain a recognizable document as it becomes a summary or a retrieved source.
Dim inactive context and brighten the current item; keep active proof text
readable. Let size reflect current importance, then reduce it when it becomes
supporting context. A date can briefly be the headline.

Use a chart only for an explained relationship. A conceptual task field can
narrow into one selected task without invented scores, thresholds or axes.
Establish the authentic article before focusing its excerpt. A graphic wrapper
does not turn it into a captured browser session.

Review intermediate states, not only the settled slide. In an optional GSAP
preview, seek inside a block and return a primitive. Returning a paused thenable
timeline from page evaluation can leave the screenshot helper waiting forever.
This issue does not apply to frame-derived Remotion state.

Use installed runtimes where practical. Whisper is the speech model executed by
faster-whisper; a second large transcription stack is not automatically needed.
OpenCV CSRT tracks a selected target, not the active speaker's identity. The
[local transcription adapter](../../../../edit/references/TOOLS.md#local-transcription-adapter)
uses FFmpeg decoding before faster-whisper when that route is selected.

Preserve approved audio when a critique cannot establish a fault. Check the
actual high-quality master before changing source text based on a blurred proxy.
Do not manufacture breaths, room tone or source wording.
