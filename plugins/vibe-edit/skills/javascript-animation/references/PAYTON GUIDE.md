# JavaScript motion

Read [the full motion profile](profile.md) and [the README](../README.md). Use [`scripts/new-piece.mjs`](../scripts/new-piece.mjs) to make a new working project; it refuses an existing destination. The bundled template is Payton's actual time→frame→sequence scene with neutral/mint colors, uninterrupted shape transformation and a settled end. It is a setup proof, not a claim that this exact graphic appeared in every finished video.

Keep randomness seeded, the frame function pure and every requested frame fully drawn before capture. Build and run repeated/out-of-order-frame checks. The Remotion bridge waits for the frame acknowledgement, uses Sequence-local frame/FPS, and cannot be replaced by a free-playing iframe. HyperFrames receives a checked rendered clip unless an actual compatible protocol is implemented and tested.

Change words, colors, timings and source assets in the copied project. Keep template and the person's profile separate. H.264 MP4 is opaque; use verified PNG/ProRes4444 for alpha. Read the runtime [GUIDE](../runtime/GUIDE.md) and [WORKFLOW](../runtime/WORKFLOW.md) for voice-timing and reference-review routes. The seven alternative upstream styles are available and licensed, but do not silently replace a selected Sketch or Gentlemen treatment with a similarly named stock style.
