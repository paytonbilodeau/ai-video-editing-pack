## Limits that remain

No native-editor import/reopen of this newly assembled motion bundle was performed, and no desktop capture was used. The portable Fusion fixture is syntax-reviewed from the previously checked native source, not freshly executed in a customer project. The person-mask route is type-checked, not claimed tested on arbitrary new human footage. The generic planar tracker rejected20/30 moving test-pattern frames; it reports those invalid rather than inventing a track. The stationary-reference fixture passed30/30. A new shot still needs representative moving-frame review.

No continuous human listening or subjective realism approval was performed. Still inspection does not cover every transition. Audio remains separately editable. No paid generation, MusicGen weight download, provider account connection or cloud upload was run by this module's verification. Full upstream optional workflow code is included, but only the explicitly listed paths were executed. Historical stream-copy swivel insertion is not guaranteed frame-exact; use the native editor for a critical edit.

The75-package HyperFrames install and260-package Flow install used their lockfiles in private disposable working copies. Dependency folders and test caches are not shipped. The full customer bundle has its own setup, profile-preservation and release-verification record.
