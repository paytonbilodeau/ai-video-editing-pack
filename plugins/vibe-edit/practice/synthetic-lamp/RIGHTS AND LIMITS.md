# Rights and limits

The lamp artwork was generated originally for Payton's Vibe Editors revision. It is an illustration, not a photograph or an application screenshot. Original PNG bytes are preserved in the private production source. Video derivatives keep the image proportions.

The click, tone and hum are mathematical signals created by the included Python build script. They contain no sampled recording, music, voice model or third-party voice. No macOS System Voice audio was generated or used.

Prepared instruction cards use rasterized system font text. No font file is redistributed. The media does not impersonate a speaker or claim a customer result.

The timeline helper is the existing Vibe Editors cut-list exporter by Payton Bilodeau; its own pack terms remain applicable. The build script calls a supplied copy rather than silently downloading or installing a replacement.

This fixture demonstrates trimming, preserving a meaningful sound/hold, simple caption timing, editable interchange and a bounded sound-filter mechanism. It does not demonstrate complete-word editing, recorded microphone cleanup, skin-tone grading, native-editor connection or automatic publication. Those require separate real-source checks.

The two XML files contain a privacy-safe `source.mp4` placeholder. Run the local relink script or relink in the editor. Local regenerated XML contains that user's chosen media path and should not be republished accidentally.

Production is private until the main release owner completes review, native acceptance and the applicable distribution policy. A successful build or local playback file is not public publication.
