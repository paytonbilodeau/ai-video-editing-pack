# 01 · Set up your AI editor

[Open the plugin README](<../../README.md>) · [Open the setup image](<assets/01-open-and-check.webp>)

 

Reading time: about 2 min.

Vibe Edit is a plugin for your AI assistant. It supplies Payton-derived editing workflows, tools and starting preferences. Your video editor holds the edit. Setup reuses an existing profile or creates an editable copy of those starting preferences.

![The pack supplies instructions to the AI assistant, which works with a separate video editor while originals remain available.](<assets/01-workspace-map.webp>)

### 1. Install the plugin

Open Codex (the ChatGPT desktop app or the Codex CLI) or Claude Code and paste this line. The assistant adds the plugin and confirms the skills loaded. It will ask you to reload or start a new session once.

> Read https://raw.githubusercontent.com/paytonbilodeau/ai-video-editing-pack/main/plugins/vibe-edit/INSTALL.md and set up Vibe Edit for me.

The commands it runs are in [INSTALL](<../../INSTALL.md>) if you prefer to type them yourself. Use [the detailed setup lesson](<../guide/01.md>) if needed.

![Install the plugin in the AI app, then check loaded skills, tested editor actions and remaining manual steps.](<assets/01-open-and-check.webp>)

### 2. Paste this setup message

> Set up Vibe Edit as my video editor and run the practice edit.

The assistant checks the tools you already use, keeps your editing profile outside the plugin, finds a working route to your editor, and asks only about choices that affect the first test.

![The plugin is separate from the private editing profile, footage and projects, so updates can preserve them.](<assets/01-private-folders.webp>)

### 3. Check the result

Setup should show your active profile, the connected editor and route, the saved test project and export, and the checks performed. The included lamp practice is the first test; your own recording can come later. A generated timeline file is not a verified native import.

![A project folder organizes files; the AI app permissions determine access to files, folders and online services.](<assets/09-permissions.webp>)

Your working preference controls how hands-on setup feels. App permissions control actual access. These are teaching drawings; your app may look different.

If something fails, share the step, error and app versions in Questions & Chat.
