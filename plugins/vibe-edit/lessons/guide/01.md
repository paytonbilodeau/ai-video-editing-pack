# 01 · Get your AI editing pack

[All 22 lessons](<../README.md>) · [Open the plugin README](<../../README.md>)

Reading time: about 3 min.

You describe the video you want, and your AI works through the edit using the tools on your computer. Then you watch the result and tell it what to improve. I'm calling that vibe editing.

The pack is now a plugin called Vibe Edit. It carries a portable version of my editing workflows, tools and starting preferences. Keep that starting look or change it for your videos; your existing custom profile takes priority.

![Your first edit starts with footage, a practical instruction pack, an AI rough cut, and your own finishing judgment.](<assets/lesson-01.jpg>)

Start with these three steps. You can begin setup before your own footage is ready; the first editing test uses the included lamp practice.

1. **Open your local AI assistant.** Codex (the ChatGPT desktop app or the Codex CLI) or Claude Code. A browser chat can talk about editing, but it cannot reach your files or your video editor.
2. **Install the plugin.** Paste this one line. The assistant adds the plugin, confirms the skills loaded, and tells you when it needs one click from you.

> Read https://raw.githubusercontent.com/paytonbilodeau/ai-video-editing-pack/main/plugins/vibe-edit/INSTALL.md and set up Vibe Edit for me.

   If you would rather type the commands yourself, they are two lines in Claude Code (`claude plugin marketplace add paytonbilodeau/ai-video-editing-pack`, then `claude plugin install vibe-edit@vibe-editors`) and two in Codex (`codex plugin marketplace add paytonbilodeau/ai-video-editing-pack`, then `codex plugin add vibe-edit@vibe-editors`). [The install page](<../../INSTALL.md>) has them ready to copy.

3. **Run setup.** Once the skills are loaded, paste this message. The assistant checks the tools you already use, keeps your editing profile outside the plugin, asks only what matters for the first test, and shows what worked.

> Set up Vibe Edit as my video editor and run the practice edit.

The plugin includes the editing workflows, source review, sound, color, captions, motion tools, reusable styles and [all 22 illustrated lessons](<../README.md>). The assistant opens what the current job needs; you do not have to install every tool before editing.

Share which editor you use and what you want to make in [Vibe Editors](<https://www.skool.com/vibeeditors?utm_campaign=skool_link_classroom&utm_content=42041b66d6e64317a930b9e046188b34>) if you would like help. The free plugin and guide work independently.

Bookmark [the plugin README](<../../README.md>) so you can find the setup instructions again.
