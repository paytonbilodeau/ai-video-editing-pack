# Review Checklist

Review the new MP4 from start to finish. Keep the source unchanged even after this passes.

- [ ] The report says `rendered; video stream, audio stream, and duration verified`, not `dry-run plan only`.
- [ ] The report names the approved plan used for this render.
- [ ] The opening starts at the intended line.
- [ ] Every marked restart keeps the corrected take.
- [ ] Every exact `--cut` removed only the approved range.
- [ ] Words do not sound clipped at cut points.
- [ ] Deliberate pauses still feel natural.
- [ ] Played clips, music, and screen media remain intact.
- [ ] Silent demonstrations and intentional visual-only sections were reviewed and protected before silence cutting.
- [ ] Audio level is steady from the opening through the end.
- [ ] Speech sounds natural and is not heavily compressed.
- [ ] No useful repeated explanation was removed.
- [ ] Every long cut matches the report.
- [ ] The source and output are different files.
- [ ] The output has one video stream and one audio stream.
- [ ] The source had no subtitle streams or chapters that needed to be preserved.
- [ ] I understand source metadata was stripped and the encoder may add technical tags.
- [ ] The output imports into the final editor.
- [ ] Color looks correct; an HDR source was not flattened accidentally.
- [ ] Final delivery loudness is metered in the final editor if a specification applies.
