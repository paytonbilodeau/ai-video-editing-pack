# 01 · Set up your AI editor

[Open START HERE](<../../START HERE.md>) · [Open the setup image](<assets/01-open-and-check.png>)

 

Reading time: about 2 min.

The complete pack supplies Payton-derived editing workflows, tools and starting preferences. Your video editor holds the edit. Setup reuses an existing profile or creates an editable copy of those starting preferences.

![The pack supplies instructions to the AI assistant, which works with a separate video editor while originals remain available.](<assets/01-workspace-map.png>)

### 1. Open the downloaded pack

Unzip the download: double-click on a Mac, or right-click and choose Extract All on Windows. Keep the Vibe Editors folder together.

Open the complete Vibe Editors folder in a Local project in Codex or a local Claude Code project. Setup makes a separate working copy and shows which tools are available. Use [the detailed setup guide](<../lessons/01.md>) if needed.

![Unzip Vibe Editors, open its folder in the AI app, then check readable files, tested editor actions and remaining manual steps.](<assets/01-open-and-check.png>)

### 2. Paste this setup message

> Set up this editing system for my videos. Read `Payton Editing System/setup/SKILL.md`, find the full bundle manifest, and reuse the tools and preferences already available. Create a separate working copy and use my existing editing profile if there is one. Otherwise, copy the included Payton-derived profile so it can be changed without touching the original. Ask only about choices that affect the first test. Run a short disposable edit from `Practice/synthetic-lamp/` through the available editor route, then show the saved project and export, what was checked, and any step that still needs a manual action. Name the downloaded source folder, the working workspace, the active profile and the loaded skill path. Tell me which folder to open for my next edit. Do not publish anything or connect a paid service without my choice.

![The downloadable pack is separate from the private editing profile, footage and projects, so updates can preserve them.](<assets/01-private-folders.png>)

### 3. Check the result

Setup should show your active profile, the copied pack, the saved test project/export and checks performed. Use Practice/synthetic-lamp/ for the first test; your own recording can come later. A generated timeline file is not a verified native import.

![A project folder organizes files; the AI app permissions determine access to files, folders and online services.](<assets/09-permissions.png>)

Your working preference controls how hands-on setup feels. App permissions control actual access. These are teaching drawings; your app may look different.

If something fails, share the step, error and app versions in Questions & Chat.
