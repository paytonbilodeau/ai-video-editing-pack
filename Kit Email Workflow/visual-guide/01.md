# 01 · Set up your AI editor

[Download the free pack](https://github.com/paytonbilodeau/ai-video-editing-pack/releases/latest/download/ai-video-editing-pack.zip) · [Open the setup image](assets/01-open-and-check.png)

Reading time: about 2 min.

The pack guides your AI; your video editor holds the edit. No recording is needed for setup.

![The pack supplies instructions to the AI assistant, which works with a separate video editor while originals remain available.](assets/01-workspace-map.png)

## 1. Open the downloaded pack

Unzip the download: double-click on a Mac, or right-click and choose Extract All on Windows. Keep the Vibe Editors folder together.

In Codex, start a Local task in your editing folder and give it the extracted pack’s location. For Claude Code, use [the detailed setup guide](../lessons/01.md).

![Unzip Vibe Editors, open its folder in the AI app, then check readable files, tested editor actions and remaining manual steps.](assets/01-open-and-check.png)

## 2. Paste this setup message

```text
Set up this Vibe Editors folder so you can be my video editor. Read its START HERE guide and follow the setup skill. Ask how hands-on I want to be: careful, balanced, or handle it for me. Reuse my existing tools, permissions, skills and preferences. Keep my originals and projects safe, and keep my private editing profile outside the pack. Explain any new access, upload, installation or cost before using it unless already authorized. Offer useful optional tools, then set up what fits. List a few files you can read in this pack, show where my private editing profile is saved, and separate editor actions you tested from actions that still need me. Tell me the simplest next step. No footage is needed for setup.
```

![The downloadable pack is separate from the private editing profile, footage and projects, so updates can preserve them.](assets/01-private-folders.png)

## 3. Check the result

Setup should show readable pack files, your saved profile, tested editor actions and any manual step. Keep your profile, footage and projects outside the pack.

![A project folder organizes files; the AI app permissions determine access to files, folders and online services.](assets/09-permissions.png)

Your working preference controls how hands-on setup feels. App permissions control actual access. These are teaching drawings; your app may look different.

If something fails, share the step, error and app versions in Questions & Chat.
