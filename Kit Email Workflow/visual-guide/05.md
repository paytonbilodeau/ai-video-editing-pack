The viewer needs to read the words and see what they explain. In the lamp illustration, a caption must leave the switch visible.

## Create useful captions

![A caption covering the lamp switch moves into clear space so the viewer can see the action.](assets/05-caption.png)

For spoken footage, use the prompt below. For the synthetic lamp practice, caption the useful click; do not invent speech.

```text
Create captions from this video's final cut, or import my subtitle file and align it to that cut. Correct names, numbers and punctuation against the recording. Keep each line readable, time it to the speech, and keep it clear of faces and the demonstration. Keep the captions editable. Return captions built into the video or a separate subtitle file as my destination requires, then check the export at normal speed and phone size.
```

## Add a graphic only if it helps

![A simple arrow directs attention to the object being explained; extra decorations are left out.](assets/05-graphics-help.png)

An arrow, label or diagram should name, point to or explain something. Your first edit does not need custom motion graphics.

```text
If the lamp switch is hard to find, add one simple pointer that helps the viewer see it. Keep the source editable and leave out decoration that adds no explanation.
```

## Play it at viewing size

![The same graphic is checked on a phone and a larger screen with readable type and space around important content.](assets/05-phone-readability.png)

Check the actual video at normal speed and phone size. Give words enough time and keep them clear of faces, actions and platform controls.

```text
Review captions over the actual footage. Check spelling, timing, placement and readability. If the video is vertical, check the crop and keep the switch visible throughout.
```

Check the delivered subtitle file or exported video too.
