# Lesson 15

Subject: Don't waste the correction you just made

Delay: 1 day after the previous lesson

After I add my final touches, I want the AI to understand what I changed and why. Otherwise, I'm likely to correct the same thing again next time.

Give it the timeline before your changes and the version you've approved. If the editor connection can read timeline data, have it compare the edits. If it can't, use before-and-after exports with timestamped notes.

Illustration: Save an accepted correction and its reason as a reusable editing preference.

Ask your AI:

> Compare my approved version with your previous edit. Explain only changes you can verify, and ask why I made a change when the reason isn't clear. Separate this video's choices from preferences worth reusing.
>
> Propose one precise update to my private editing profile. Save it after I approve it and tell me the file location. Read that saved profile at the start of the next project.

“Keep a pause when the viewer needs time to read the settings” is a useful preference. “Never leave pauses” will make the next tutorial exhausting.

An editing profile is a file of preferences and accepted rules. Start with [the template](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/templates/EDITING%20PROFILE.md) and save your filled-in copy in a stable private folder outside the downloaded pack. Give the AI its location at the start of each project.

The saved file is what carries the lesson forward. Don't rely on the next chat remembering it.

Save one accepted lesson today, then check it on another clip. If it helps, keep it; if the new context needs a different choice, adjust the instruction.
