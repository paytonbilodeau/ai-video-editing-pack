# 15 · Help your AI remember your taste

Reading time: about 2 min.

The best part of a good correction is not having to make it again next time. That’s what your editing profile is for: a private file of preferences the AI reads before it edits.

Give it the timeline before your changes and the version you've approved. If the editor connection can read timeline data, have it compare the edits. If it can't, use before-and-after exports with timestamped notes.

![Save an accepted correction and its reason as a reusable editing preference.](../assets/lesson-15.jpg)

Ask your AI:

> Compare my finished version with your previous edit. Explain only changes you can verify. Save clear reusable preferences in my existing editing profile, with an example and when they apply. Ask only if the reason is unclear or this could be a one-video exception. Preserve the previous profile version and read the updated file before my next edit.

“Keep a pause when the viewer needs time to read the settings” is a useful preference. “Never leave pauses” will make the next tutorial exhausting.

The setup prompt creates or reuses this profile on day one and saves its location in your assistant’s project instructions. It lives outside the pack, so downloading an update won’t erase your taste. [The template](../../AI%20Video%20Editing%20Pack/templates/EDITING%20PROFILE.md) shows the questions it can remember. If you already have preferences or skills, it should preserve them and ask about conflicts rather than replace them with defaults.

The AI needs access to that file in later sessions. If you switch apps or start an unrelated workspace, give it the profile folder again. Saving a file doesn’t retrain a model or make every chat remember it.

Taste also depends on the video. A tutorial may need room to read a menu; a punchy announcement may not. Useful preferences describe when they apply, so your editor can adapt instead of repeating a rule blindly.
