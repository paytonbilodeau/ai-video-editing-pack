# 03 · Write a clear editing brief

[All 22 lessons](<../SEQUENCE.md>) · [Open START HERE](<../../START HERE.md>)

Reading time: about 3 min.

“Edit my video” leaves quite a lot up for interpretation. Give the AI the exact recording and a clear idea of what the finished video should do.

Keep that recording in a project folder with any script, screen recordings and assets it needs. Name the file clearly, such as desk-tutorial-take-2.mp4, and point the AI to your existing editing profile and project. That lets it build on your setup instead of starting over.

If setup copied the Payton-derived profile, that is your starting taste. Change only what you want to change, such as colors, captions or pacing. An existing custom profile stays in charge; this video’s specific instructions belong in its brief.

![Name the source recording and describe the result you want in an editing brief.](<../assets/editing-brief.png>)

Your brief connects those files to the result you want. For example:

> Edit desk-tutorial-take-2.mp4 for someone trying this tool for the first time. Use my editing profile and current editor. Remove clear mistakes, abandoned starts, repeated takes and dead space. Keep complete explanations, useful pauses and enough time to see each screen action. Preserve the opening's setup and payoff. Work on a duplicate, editable timeline, check the result, and return the project and export with anything I should review.

The timeline is where your editor arranges the clips, audio and graphics. Its first usable version is the rough cut: the right material in the right order. For this tutorial, that means someone can follow the explanation and see each action. A shorter cut is only useful if it still makes sense.

If you have more precise directions, put them beside the relevant script line. Say which screen recording to show or when a graphic should appear. Tell the AI to read document comments and replies too, because copying only the script text can lose those notes.

You can ask for a short preview when you're trying a new style. Otherwise, ask it to finish the agreed edit without stopping at every stage. Keep the editor you already know; the pack's [Resolve](<../../AI Video Editing Pack/references/EDITOR PLAYBOOK RESOLVE.md>), [Premiere](<../../AI Video Editing Pack/references/EDITOR PLAYBOOK PREMIERE.md>), [Final Cut](<../../AI Video Editing Pack/references/EDITOR PLAYBOOK FINAL CUT.md>) and [CapCut](<../../AI Video Editing Pack/references/EDITOR PLAYBOOK CAPCUT.md>) guides help your AI check the available connection.

### Put this into practice

Write one brief with a filename, audience, purpose and deliverables.

### Preserve the opening promise

Name the opening’s setup and payoff, then have the AI record its source range before assembly. Check that the opening and transition survive the cut. A later explanatory sentence may lose the reason to watch. If the AI proposes another opening, have it explain how that choice serves the same audience and promise.
