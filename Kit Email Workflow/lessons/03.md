# Lesson 3

Subject: Tell it which video. Exactly which video.

Delay: 1 day after the previous lesson

“Edit my video” leaves quite a lot up for interpretation. The AI needs to know which recording to use and what a good edit should accomplish.

Put a copy of one recording in its own project folder. Give it a recognizable name, like desk-tutorial-take-2.mp4. Your source file is the recording you're editing; the timeline is the sequence of clips, audio and graphics inside your editor.

Illustration: Choose the exact source file and a short test section before starting the edit.

Give your AI a brief like this, changing the filename and purpose to match your video:

Work on desk-tutorial-take-2.mp4 in my project folder. This is a tutorial for someone trying the tool for the first time. Inspect the recording and propose a rough cut that removes clear mistakes, repeated takes and dead space. Keep complete explanations, useful pauses and enough time to see each screen action. Use a duplicate, editable timeline. Show me the plan, then edit the first minute once I approve it. Stop there so I can review the result.

A rough cut is the first usable version of the story. We're getting the right material in the right order before spending time on the polish. For a tutorial, cutting out the explanation someone needs is a bad trade, even if the video becomes shorter.

Use the editor you already know. I use DaVinci Resolve and would start there if I were choosing from scratch. Final Cut, Premiere and CapCut have different connection options, which [the editor guide](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/references/EDITOR%20CONNECTIONS.md) covers.

Approve the first-minute plan, let the AI make that section, then export and watch it. If it understands the brief, continue with the rest. If it doesn't, fixing one minute is a much nicer afternoon than fixing the whole video.
