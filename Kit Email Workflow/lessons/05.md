# Lesson 5

Subject: The boring first pass can be automatic

Delay: 1 day after the previous lesson

Sometimes I don't need the AI to make creative decisions yet. I want it to remove obvious dead space so I can start from a cleaner recording.

The pack links to a separate [free pre-edit tool](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/skills/pre-edit/SKILL.md) that runs on your computer. It isn’t bundled in the main ZIP. It needs Python and FFmpeg, which processes the video; some detection options also need a local speech model. Your AI can check what’s installed and explain any additions.

Illustration: Review a proposed pre-edit plan on a copied clip before generating a first pass.

Ask your AI:

> Use the optional local pre-edit route only if it fits this recording and computer. Check the requirements and ask before any new installation. Generate and inspect a dry plan showing the source, removal ranges, reasons and output location. Use conservative settings, keep the original intact and complete the requested first pass. Stop if the plan has a material problem you cannot resolve. Include the plan with the result.

A dry plan lists the proposed changes without applying them. The AI should inspect it before rendering; you can ask to see it first too. A quiet word, a thoughtful pause and a genuine mistake can all look like low-volume audio. Aggressive silence removal can damage a good recording.

The result is a flattened MP4: one finished video file, rather than a timeline of separate cuts. You can import it into an editor, but you can't simply drag each removed section back into place. Keep the source and removal plan so you can render a different first pass.

For separate, adjustable cuts, the pack also includes a [timeline-file exporter](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/references/CUT%20LIST%20EXPORT.md). It turns a list of source ranges into files compatible editors can import. If your current workflow already produces a good rough cut, skip the extra route. I’d rather finish the video than add a tool because it exists.
