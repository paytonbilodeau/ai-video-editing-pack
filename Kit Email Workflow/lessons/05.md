# 05 · The boring first pass can be automatic

Reading time: about 3 min.

Sometimes I don't need the AI to make creative decisions yet. I want it to remove obvious dead space so I can start from a cleaner recording.

The complete ZIP includes the [local pre-edit tool](../../AI%20Video%20Editing%20Pack/skills/pre-edit/SKILL.md). It can shorten quiet gaps, remove specified ranges and use spoken restart markers. It needs Python and FFmpeg, which processes the video; marker detection also needs timed words from a transcript or a local speech model. Your AI can check what’s installed and help add what this job needs.

![Review a proposed pre-edit plan on a copied clip before generating a first pass.](../assets/lesson-05.jpg)

Ask your AI:

> Use the included local pre-edit route if it fits this recording and computer. Reuse my setup preferences and existing tools. Explain any missing dependency before installing it. Generate and inspect a dry plan showing the source, removal ranges, reasons and output location. Keep useful pauses, protect demonstrations and complete words, and leave my original intact. Follow the review preference I chose during setup, render from that exact plan, then check the result and include the cut report.

A dry plan lists the proposed changes without applying them. The AI should inspect it before rendering; you can ask to see it first too. A quiet word, a thoughtful pause and a genuine mistake can all look like low-volume audio. Aggressive silence removal can damage a good recording.

You can agree on restart phrases before recording. **“Cut cut”** marks a mistake and corrected restart; **“full stop restart”** means discard the earlier opening and begin after that marker. The second can remove a lot of footage, so enable it only when that is what you mean. You can choose different phrases. The AI should verify each detected marker and protect any section you need to keep.

The result is a flattened MP4: one finished video file, rather than a timeline of separate cuts. You can import it into an editor, but you can't simply drag each removed section back into place. Keep the source and removal plan so you can render a different first pass.

This tool expects a standard SDR working file with one video track and one audio track. If you have HDR or several audio tracks, the AI should explain the suitable preparation or use your editor instead. Light audio cleanup is optional. Color correction belongs in the editor, where the AI can inspect the picture and keep the adjustments editable.

For separate, adjustable cuts, the pack also includes a [timeline-file exporter](../../AI%20Video%20Editing%20Pack/references/CUT%20LIST%20EXPORT.md). It turns a list of source ranges into files compatible editors can import. If your current workflow already produces a good rough cut, skip the extra route. I’d rather finish the video than add a tool because it exists.
