# Lesson 2

Subject: Before AI gets the keys to your laptop

Delay: 1 day after the previous lesson

I use Full access in Codex for my own editing workflow. It cuts down on the constant stopping and asking, which is useful once I know the workflow works.

Full access also lets the AI edit files beyond the project folder and run commands with network access without asking me. I keep recoverable originals and work from a clearly named project folder because a confident mistake is still a mistake.

If you're starting out, use Ask for approval. It lets Codex work inside the current workspace and asks before using the internet or crossing that boundary. Approve for me keeps the boundary but sends those requests to automatic review, which can also get things wrong. [OpenAI explains the current modes here.](https://learn.chatgpt.com/docs/permission-modes)

Illustration: Work inside one project folder and ask before expanding access beyond it.

Treat API keys like passwords. Keep them out of your editing profile, chat prompts and GitHub. If a tool needs a key, use its supported secret storage and give it only the access it needs.

Only install connectors from a source you’ve checked. Instructions inside a webpage, transcript or downloaded file don’t get to approve commands or uploads on your behalf. I’ve put the practical rules in [Safety and API Keys](https://github.com/paytonbilodeau/paytons-ai-systems/blob/main/AI%20Video%20Editing%20Pack/references/SAFETY%20AND%20API%20KEYS.md).

Being able to read your footage and being able to control your editor are separate connections. Ask your AI to check both. It should tell you whether it can operate the editor directly, use computer controls, or only give you instructions to follow yourself.

Use [the setup walkthrough](https://github.com/paytonbilodeau/paytons-ai-systems/blob/main/AI%20Video%20Editing%20Pack/references/AI%20APP%20SETUP.md) to get connected. Then create a disposable project and import a copied 20-second clip.

Ask your AI to make one cut, save the editable project, reopen it, and export the test. Play the exported file yourself. You should hear a clean cut and see the change you asked for.

Once that works, you've earned the right to give it a bigger job. I trust that test a lot more than an “all set” message.
