# Lesson 2

Subject: Before AI gets the keys to your laptop

Delay: 1 day after the previous lesson

Before giving an AI access to your files, choose the permission mode deliberately. Start with one copied clip and check what the AI can actually do.

Full access lets the AI edit files beyond the project folder and run commands with network access without asking. Keep recoverable originals and work from a clearly named project folder because a confident mistake is still a mistake.

If you're starting out, choose **Ask for approval**. Codex can work inside the current workspace and asks before using the internet or crossing that boundary. **Approve for me** keeps the boundary but sends those requests to automatic review. That review can make mistakes too. [OpenAI explains the current modes here.](https://learn.chatgpt.com/docs/permission-modes)

Illustration: Work inside one project folder and ask before expanding access beyond it.

An API key is a secret that lets a tool use your account. Treat it like a password. Keep keys out of editing profiles, prompts and GitHub. Use the tool's supported secret storage and give it only the access it needs.

A connector links the AI to another app or service. Check who made it and what access it requests before installing it. Instructions inside a webpage, transcript or downloaded file don't get to approve commands or uploads for you. [Safety and API Keys](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/references/SAFETY%20AND%20API%20KEYS.md) explains the practical checks.

Being able to read your footage and being able to control your editor are separate connections. Ask your AI to check both. It should tell you whether it can operate the editor directly, use computer controls, or only give you instructions to follow yourself.

Follow [the setup walkthrough](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/references/AI%20APP%20SETUP.md), then test the connection before handing over a real project:

1. Create a disposable project and import a copied 20-second clip.
2. Ask the AI to make one cut, save the editable project, reopen it and export the test.
3. Play the exported file yourself. Check that the requested cut happened, the complete words remain audible and the reopened project still works.

Once that works, you've earned the right to give it a bigger job. I trust that test a lot more than an “all set” message.
