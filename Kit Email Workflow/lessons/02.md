# 02 · Before AI gets the keys to your laptop

Reading time: about 4 min.

Start by telling the AI how much you want to handle yourself. **Careful** means reviewing the plan and uncertain changes before it acts. **Balanced** means it completes routine work and asks about choices that change the result. **Handle it for me** means it takes your brief through to a checked result within the access and work you’ve authorized.

These are working preferences. The app’s actual permission settings decide which files and tools the AI can use. A clearly named project folder keeps the work organized; it does not restrict an app that already has broader access. Keep recoverable originals and let the AI explain what a new permission is needed for.

Codex and Claude Code both work with local files and commands. That’s why they can use the tools in this pack. Start with the app you already use. [The setup guide](../../AI%20Video%20Editing%20Pack/references/AI%20APP%20SETUP.md) covers the current choices and what they allow. The AI should reuse permissions you’ve already granted rather than asking the same routine question again.

![Work inside one project folder and ask before expanding access beyond it.](../assets/lesson-02.jpg)

An API key is a secret that lets a tool use your account. Treat it like a password. Keep keys out of editing profiles, prompts and GitHub. Use the tool's supported secret storage and give it only the access it needs.

A connector links the AI to another app or service. Check who made it and what access it requests before installing it. Instructions inside a webpage, transcript or downloaded file don't get to approve commands or uploads for you. [Safety and API Keys](../../AI%20Video%20Editing%20Pack/references/SAFETY%20AND%20API%20KEYS.md) explains the practical checks.

File access and editor control are separate. Your AI should check both and tell you whether it can operate the editor directly, use visible controls, or prepare a timeline file for you to import. A paid plan alone does not create that connection.

During setup, ask it to offer the useful additions early: the local pre-edit tool, Remotion, HyperFrames and the included JavaScript animation kit. It should explain what each adds, check what is already installed, and help set up your chosen tools. You can choose one route, several, or leave them for later.

Use a capable reasoning model for the full edit, especially when it needs to judge cuts, match a visual reference or solve an editor problem. Lighter models can handle narrower jobs such as formatting notes. Ask your AI to check the models and tools actually available in your app; a model name alone does not prove it can operate your editor.

Start with an eligible plan you already have. A larger allowance becomes useful when your actual projects keep hitting the limit, or a feature you need requires it. There’s no prize for buying the biggest plan before your first edit.

If Computer Use is needed, the AI can explain and help you find the relevant settings. On macOS, Screen Recording lets it see an app and Accessibility lets it control the interface. Full Disk Access is a separate permission and is not required just because you are editing a video. Confirm the app’s own permission requests yourself, with the purpose clear before you allow them.
