# Lesson 2

Subject: Before AI gets the keys to your laptop

Delay: 1 day after the previous lesson

Before giving an AI access to your files, choose the permission mode deliberately. Have the AI check what it can actually do in the intended working folder.

Full access lets the AI edit files beyond the project folder and run commands with network access without asking. Keep recoverable originals and work from a clearly named project folder because a confident mistake is still a mistake.

If you want to review wider access yourself, choose **Ask for approval**. **Approve for me** sends those requests to automatic review instead. Both keep a workspace boundary; automatic review can make mistakes too. [The setup guide](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/references/AI%20APP%20SETUP.md) explains the current choices.

Illustration: Work inside one project folder and ask before expanding access beyond it.

An API key is a secret that lets a tool use your account. Treat it like a password. Keep keys out of editing profiles, prompts and GitHub. Use the tool's supported secret storage and give it only the access it needs.

A connector links the AI to another app or service. Check who made it and what access it requests before installing it. Instructions inside a webpage, transcript or downloaded file don't get to approve commands or uploads for you. [Safety and API Keys](https://github.com/paytonbilodeau/ai-video-editing-pack/blob/main/AI%20Video%20Editing%20Pack/references/SAFETY%20AND%20API%20KEYS.md) explains the practical checks.

File access and editor control are separate. Your AI should check both and tell you whether it can operate the editor directly, use visible controls, or prepare a timeline file for you to import. A paid plan alone does not create that connection.

For difficult editing decisions, GPT-6 Astra with High reasoning is an option for complex judgment. GPT-6.1 Sol is a capable everyday choice at lower usage cost. Lighter models suit narrower jobs, like formatting notes. More reasoning helps with complicated decisions; it doesn’t magically improve a bad brief.

Start with an eligible plan you already have. A larger allowance becomes useful when your actual projects keep hitting the limit, or a feature you need requires it. There’s no prize for buying the biggest plan before your first edit.

**Full Disk Access** is a separate macOS setting, not Codex’s Full access. Computer Use normally needs Screen Recording to see the app and Accessibility to control it. Grant a permission for a stated need. “Always allow,” where offered, should apply to an editor you intend the AI to keep using.
