# 01 · Get your AI editing pack

[All 22 lessons](<../SEQUENCE.md>) · [Open START HERE](<../../START HERE.md>)

Reading time: about 3 min.

You describe the video you want, and your AI works through the edit using the tools on your computer. Then you watch the result and tell it what to improve. I'm calling that vibe editing.

The pack includes a portable version of my editing workflows, tools and starting preferences. Keep that starting look or change it for your videos; your existing custom profile takes priority.

![Your first edit starts with footage, a practical instruction pack, an AI rough cut, and your own finishing judgment.](<../assets/lesson-01.jpg>)

Start with these three steps. You can begin setup before your own footage is ready; the first editing test uses the included lamp practice.

1. **Download and unzip the pack.** A ZIP is a compressed folder. Double-click it on a Mac, or right-click and choose Extract All on Windows. Keep the complete Vibe Editors folder together.
2. **Open the extracted pack in your local AI assistant.** Use a Local project in Codex or a local project folder in Claude Code. Give it the complete Vibe Editors folder. Setup makes a separate working copy and keeps your profile and footage outside it. [App setup details](<../../Payton Editing System/setup/APP SETUP.md>).
3. **Paste this message.** The assistant checks the tools you already use, asks only what matters for the first test, and shows what worked.

> Set up this editing system for my videos. Read `Payton Editing System/setup/SKILL.md`, find the full bundle manifest, and reuse the tools and preferences already available. Create a separate working copy and use my existing editing profile if there is one. Otherwise, copy the included Payton-derived profile so it can be changed without touching the original. Ask only about choices that affect the first test. Run a short disposable edit from `Practice/synthetic-lamp/` through the available editor route, then show the saved project and export, what was checked, and any step that still needs a manual action. Name the downloaded source folder, the working workspace, the active profile and the loaded skill path. Tell me which folder to open for my next edit. Do not publish anything or connect a paid service without my choice.

The complete download includes the editing workflows, source review, sound, color, captions, motion tools, reusable styles and [all 22 illustrated lessons](<../SEQUENCE.md>). The assistant opens what the current job needs; you do not have to install every tool before editing.
