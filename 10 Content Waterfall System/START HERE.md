# Clips and posts from a longer video

The full editing pack also works on videos recorded as shorts. This optional waterfall route starts with a longer recording and selects smaller, self-contained ideas from it. Keep enough context for a new viewer. A short can inspire a longer video, but that usually requires new recording.

For moving faces, start with your editor's native automatic reframing and use [the reframing guide](../AI%20Video%20Editing%20Pack/references/REFRAMING.md). The standalone crop tool keeps one fixed frame.

Give the AI a recording and say which outputs you want. It should find useful
complete ideas, choose their source ranges, prepare the requested clips and
captions, and keep every claim tied to the original.

The complete download includes the local tools. Python 3.11, FFmpeg and ffprobe
are needed for extraction. A word-timed transcript supports exact captions;
the assistant can reuse a compatible transcript or explain a transcription
option before setting it up. No transcription model is bundled.

## Give your AI this message

```text
Use the included Content Waterfall System for the outputs I requested. Read SYSTEM.md, INSTALL.md and CURRENT LIMITS AND PROOF.md. Reuse my source, profile, working pace and permissions. Build the claim ledger and content map yourself. Choose complete useful ideas with an opening that makes sense alone and an ending that pays it off. Preserve the source's meaning and complete words. Record my existing request as authorization for the named output types. Validate the map and source hash before extracting; ask for another approval only if I requested a checkpoint or there is a material uncertainty outside my instructions. Use a new output folder. Check the actual clips, crop and captions, then deliver them for feedback. Offer to set up missing local tools with a plain explanation. Keep publication and account changes separate from creating these files.
```

A file-aware assistant can prepare the map and drafts. A local tool connection
is needed to extract and verify video. The assistant should explain which
route it can actually use instead of claiming a render it cannot perform.

## What makes a good clip

The opening earns attention without relying on missing context. The clip
contains the explanation or example that pays it off, retains important
qualifications and finishes the thought. Choose fewer strong clips over weak
ones added to fill a quota.

Keep faces, captions and demonstrations readable throughout the movement. A
static crop is a starting option. When it hides an important action, use an
editor layout that shows the action clearly. The bundled extractor does not
track faces automatically.

## What you get

The requested outputs, source timestamps, captions when suitable timed words
exist, and a short review record. Titles and text drafts use claims the source
actually supports. Exporting the files does not publish them.

The assistant can run a neutral synthetic test without assigning you a practice
recording. Tests prove the extraction mechanics, not how compelling the clips
are. [Current limits and evidence](CURRENT%20LIMITS%20AND%20PROOF.md) distinguish
those checks from review of a real production edit. There is no promised setup
time, output count or audience result.
