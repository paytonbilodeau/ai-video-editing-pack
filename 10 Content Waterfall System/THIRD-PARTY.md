# Third-Party Notes

## Python

The supplied tools use the Python standard library and require Python 3.11 or newer.

## FFmpeg and ffprobe

Local media extraction and probing require FFmpeg and ffprobe installed separately. FFmpeg builds and enabled codecs vary by distributor. Review the license and build configuration supplied with your installation at https://ffmpeg.org/legal.html.

The tools call FFmpeg as a separate program. No FFmpeg binary or source is included.

## Transcription and tracking

No transcription model, API client, face-tracking library, or model weight is bundled. You may supply an approved word-timed transcript from another tool after checking its current cost, privacy, and usage terms. Dynamic face tracking is not included.

## Platforms

Social-platform formats, limits, and terms change. Verify current official requirements before delivery. This system creates local packages and does not connect to or publish on a platform.
