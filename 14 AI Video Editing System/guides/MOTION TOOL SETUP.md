# Set up motion graphics with your AI

The complete walkthrough is in the pack's
[MOTION TOOL SETUP](../../AI%20Video%20Editing%20Pack/references/MOTION%20TOOL%20SETUP.md).
It covers Remotion, HyperFrames and the JavaScript kit, explains the choice in
plain language, and tells the assistant how to complete approved setup.

Keep a working project and its assets when they fit. Use native editor controls
for a simple graphic, Remotion for reusable React scenes, HyperFrames for HTML
layouts, or JavaScript for procedural drawing. They can supply separate checked
layers to the same edit. The person can choose one, several, or defer installation.

The full download includes two original examples in System 09:

- [Remotion starter](../../09%20Visual%20Storytelling%20and%20Motion%20System/INSTALL.md)
  with opaque MP4 and transparent ProRes output commands.
- [HyperFrames starter](../../09%20Visual%20Storytelling%20and%20Motion%20System/hyperframes-starter/README.md)
  with local HTML and the same two output choices.

The [JavaScript kit](../../AI%20Video%20Editing%20Pack/skills/javascript-animation/SKILL.md)
includes seven public styles, frame-driven source and a Remotion adapter.

Before the full graphic, let the AI render a short example, inspect it, import
it into the chosen editor, and save the command and versions that worked. A
rendered file and a verified editor import are different milestones. Retain the
editable source so feedback can change the design without starting over.
