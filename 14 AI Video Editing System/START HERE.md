# Start Here: AI Video Editing System

Part of the AI Video Editing Pack, created and maintained by Payton Bilodeau.

Use this system to help an AI edit a recording in DaVinci Resolve, build motion
graphics from your references, and deliver a finished video plus an editable
project. It includes setup, a small first test, cut review, visual finishing,
and a record of the corrections worth reusing.

Want only a conservative automatic pre-edit? System 05 remains a separate,
lighter option. Its local utility and settings are unchanged. You do not need
Resolve or this system to use it.

## Minimum AI capability

**Run named tools** is required to inspect media and use the setup checker.
Controlling Resolve also requires a working local connection or supported
computer use. An account name or paid AI plan does not establish either.
A chat-only assistant can complete the brief and prepare instructions, but must
call that a plan, not an edit. You can perform the editor steps yourself.

## First useful result

Start with a copied 20 to 60 second clip: one complete thought, an obvious
recording mistake, and a moment where one simple visual helps. Finish a clean
cut first, then add one original title or annotation. Save the editable project
and watch the export. This is a capability test, not a deadline or a promise
of a perfect first attempt. Software setup can take longer than the test edit.

For the full path from setup through cuts, sound, color, one graphic, review and
delivery, follow the [post-production walkthrough](guides/POST-PRODUCTION%20WALKTHROUGH.md).

## Give your AI this message

```text
Read START HERE.md, SYSTEM.md, INSTALL.md, CURRENT LIMITS AND PROOF.md, and the
project brief in templates. Help me set up an AI-assisted video editing workflow
using the tools I already have. Keep System 05 available if I only want a pre-edit.

First inspect only the folder and tools I authorize. Tell me what you can actually
read, write and run, what is already installed, and what needs setup or a license.
Use the read-only setup doctor. Follow the Resolve/MCP guide for my installed
version; prove a read-only connection before changing a project. Ask before new
installs, purchases, model downloads or broader access. Do not ask again for
actions I have already approved.

Use a short copied recording for the first test. Transcribe the actual source,
check doubtful words and recording mistakes, preserve demonstrations, improve
sound and color conservatively, and create an editable clean cut for review.
After the cuts are approved, preserve them and add one useful original visual.
Choose Remotion, Hyperframes or native Resolve tools for the specific shot.

Review the encoded result, deliver the clean and decorated masters when needed,
and reopen the project to check media availability. Record what was tested,
what someone watched or listened to, and what still needs review. Save reusable
corrections in my own style and editing skill, with examples and a rollback copy.
Keep my work under _MY WORK/AI Video Editing. Publishing is a separate action.
```

## Have these ready

- The exact recording, intended audience, platform and finished result.
- Your operating system, editor edition and AI assistant with local access.
- Protected wording, demonstrations, source audio and existing approved edits.
- Any style references you are allowed to use, plus what you like about them.
- Your choice of clean review first, finishing an approved cut, or pre-edit only.

Use `INSTALL.md` next. Do not install every tool to complete the first test.
