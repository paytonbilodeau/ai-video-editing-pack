# AI Video Editing System: Detailed Reference

Start with the [AI Video Editing Pack setup](../AI%20Video%20Editing%20Pack/START%20HERE.md).
It prepares your tools and private editing profile without needing footage.
This folder contains deeper Resolve workflows and optional technical examples.

When you request a video edit, the AI should complete the requested work and
return an editable project, export and short report. Checkpoints and short
style previews are optional. Keep originals recoverable, and ask before new
installs, purchases, uploads or broader access unless already authorized.

The [post-production walkthrough](guides/POST-PRODUCTION%20WALKTHROUGH.md)
explains cuts, sound, color, optional graphics and delivery. Its small-clip
example is available when useful; it is not a required first assignment.
The [setup guide](INSTALL.md) and [capability limits](CURRENT%20LIMITS%20AND%20PROOF.md)
help the assistant check the route honestly. A plan or passing prerequisite
checker does not prove that an editor was controlled or an export reviewed.

For only a conservative automatic first pass, see the separate
[pre-edit route](../AI%20Video%20Editing%20Pack/skills/pre-edit/SKILL.md).
Use only the parts needed for your video. Publishing remains a separate action.
