# Example: A Short Desk-Setup Explanation

This is a fictional filled-in example, not a render receipt or speed benchmark.

## Brief

The user supplies a copied 42-second SDR recording explaining where to place
a desk lamp. The target is landscape 1080p at the source frame rate. The source
has one spoken false start, an intentional silent demonstration, and a final
complete tip. The user authorizes removal of the false start, conservative audio
cleanup and one original annotation. There is no publishing request.

## Setup decision

The user already has a supported Resolve Studio installation and a local coding
assistant. The setup checker reports Python, FFmpeg and ffprobe present. That
does not prove MCP access. The assistant separately calls native status, then
tests import and a reversible edit in a disposable project. The person watches
that sample and records the exact project and export.

Native Resolve text and an arrow are sufficient for this first shot. The user
can choose the Remotion starter later; no second motion engine is installed
merely to complete a checklist.

## Cut review

The assistant compares complete takes and removes the authorized abandoned
opening. It preserves the silent lamp movement, the breath before the final
tip, and the full closing word. The transcript's plausible replacement for a
lamp brand is marked uncertain until checked against the audio. The first
review contains clean cuts, sound and restrained color, with no added graphics.

The person shortens a pause and returns the native project. The assistant saves
that actual timeline and compares source ranges. Later clips moving earlier is
ripple movement, not another set of deletions. The accepted change becomes a
specific lesson about this transition, not a universal pause limit.

## Style and final delivery

An original blue annotation points at the lamp after the user's gesture. It
stays readable through the explanation and avoids the hand. A second caption
test checks a longer sentence; the person asks for a shorter line and approves
the revision. The style record retains the licensed font, timing and examples.

The clean and decorated exports share the same cuts and original demonstration.
Only the added annotation, caption and dedicated effect sound differ. The saved
project retains both timelines and its source media locations. A successful
decode proves technical validity; the person's separate normal-speed watch and
listen establishes the recorded review. The final transcript and any packaging use final export times, not the original
source times.

The result is delivered as files. Publishing and making shorts remain separate
requests. The next run uses the saved skill but still names its exact source.
