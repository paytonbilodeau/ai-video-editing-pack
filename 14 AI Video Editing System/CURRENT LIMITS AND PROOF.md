# Current Limits and Proof

This system is an original public workflow and setup guide. It is not a bundled
autonomous editing application or a promise of exact results from any AI model.

## What the release checks establish

- The library validator checks declared files, privacy rules and the included
  offline tool suites. The new setup checker has tests for missing dependencies,
  version failures, permission checks and the distinction between presence and
  connectivity.
- Native Resolve status and its installed vendor setup documentation were
  checked on macOS with Studio 21.1. No production project was modified for this
  setup check. The checker itself never connects to Resolve.
- System 09 contains the separately tested neutral Remotion starter. Refer to
  that system for its render proof and scope. The Hyperframes guide follows
  current upstream setup instructions; a new user's first local render remains
  a required test, not a result this library can promise for their machine.
- The filled example is fictional. It demonstrates a completed record and must
  not be presented as benchmark, user research or a tested end-to-end render.

## What still requires your own test

Editor edition and licensing, Windows/Linux/native client integration, media
codecs, project import/export, actual sound, font rendering, tracking, alpha
edges, the first complete edit and the benefit of an effect all require checks
in your environment. A successful Python test does not prove those operations.

The setup checker can discover tools on the current PATH and known vendor paths.
It cannot prove an application is activated, running, connected, permitted to
edit, or capable of a particular action. It does not search a user's drive for
software. Supply a known custom MCP path when required.

Technical checks and perceptual review answer different questions. Record which
version was decoded, which intervals were inspected, and who actually watched
and listened. Do not label sampled frames or a transcript as a full review.
Preserve an existing approval within its stated scope.

This system does not publish videos, guarantee time savings, include private
style recipes or erase the need for creative judgment. System 05 remains the
original standalone pre-edit option with its existing narrower tool behavior.
