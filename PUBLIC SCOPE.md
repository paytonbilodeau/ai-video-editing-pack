# Public scope

This repository is the AI Video Editing Pack. Editing-related tools and the Kit email funnel are parts of this one offer. Today in AI, AI Mentorship and Echo Improvement each have a separate repository.

Do not add the personal memory vault, assistant setup, private agent infrastructure, general operating systems, private style recipes, customer records or personal configuration. A source change is a reason to review a public workflow, never permission to export a private system. Rewrite a reusable mechanism, inspect the diff, run validation and read back the public release.

The email workflow teaches the process and provides editable templates. It does not grant permission to publish to an author's accounts or include their private artwork recipe.
