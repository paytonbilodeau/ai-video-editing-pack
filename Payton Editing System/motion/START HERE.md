**Use one engine for the first test.** Each engine's README gives setup, exact commands and a result check. Node is needed for coded graphics; Python only for the tools chosen; FFmpeg for video/audio exports. Sketch and Doodle prompts need an image-capable assistant. Nothing here installs an image subscription or a video editor.

Copy the selected project to a new working folder before customizing. The whole-system setup makes the customer profile outside the pack; refer to it rather than changing the shipped defaults. Start with the same mint `#72DFA5`, dark green `#0F583D`, neutral palette, original typography and calm holds. Change colors, wording, avatar and timing only where requested. A new brand never needs Payton's portrait or private media.

## Make the actual video clear

One useful idea per visual state. Use real word times from the locked edit, preserve complete phrases and the speaker's meaning, and let the result remain readable. A graphic can explain, prove or compare. It does not have to appear every few seconds. Omit idle motion and repeated headlines. Keep one caption owner and inspect the complete final composite, including the longest subtitle and platform controls.

The house portrait starting regions at 1080×1920 are roughly x145–915/y380–1220 for the main visual and x180–900/y1300–1490 for subtitles. They are composition guides, not platform guarantees. Recompose landscape and portrait; match the source/project frame rate. Verify actual glyph bounds, face/action clearance and the current destination preview.

## Assets, sound and permissions

Use supplied or rights-cleared media. Authentic screenshots stay authentic. For a necessary logo in a generated scene, use the current official structure as a reference, integrate it in the scene's style and verify the mark; do not invent, flatten over or silently replace it. No third-party logo library is bundled. Keep generated examples labeled and do not present them as real product evidence.

The selected marker uses its actual CC0 source recordings and pen-event schedule. Ordinary SFX are original procedural sounds. Some optional upstream HyperFrames sounds/textures needed lawful replacements; [THIRD-PARTY](THIRD-PARTY.md) names those substitutions. They are not claims that every optional asset is one used in Payton's finished videos.

Keep paid provider keys only in your own environment. No credentials are included or discovered from Payton's files. Native or already-working local tools are preferred; optional adapters require explicit permission and current price/model checks. No broadcast, upload, publishing or automated update happens during setup.

## What the examples prove

A rendered sample proves its specific code path, fonts, dimensions and timing can render in the tested environment. It does not prove an arbitrary new composition is accurate, a new editor imports alpha correctly, or a customer likes the result. Inspect actual frames, listen with narration and import into the intended editor before final delivery. Read [VERIFICATION](VERIFICATION.md) for the current test record.

Updates belong to the existing release/review process. Keep the customer profile and working projects outside the pack. Review the source-map manifest, compare changed defaults, test a disposable copy and adopt changes deliberately. Never replace local preferences just because the pack version changed.
