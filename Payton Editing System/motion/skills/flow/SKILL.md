# Flow and Tech Motion

Read [the complete production manual](references/production-manual.md), then [the runnable project](../../flow/README.md). Flow is the toolkit; Tech Motion is the visual style. All component families and pure physics/lane libraries are included. Use the customer's profile and actual source facts. Existing correct typography wins over a generic tech preset.

The current default is a neutral dark canvas, mint emphasis, deep green only for depth, readable type and a useful change timed to the spoken thought. The original four green/aqua light/dark palettes remain in `theme.ts`. Set the palette before rendering. The customer config can replace colors and words without changing the components. Departure Mono and Instrument Serif are bundled with their licenses.

Build one persistent visual relationship, evolve its states, allow reading time and return to the presenter when their judgment carries the point. Use real artifacts for proof. Cards, terminal, charts, counters, meters, checklist, drawing, motion, evidence and fixed-step physics remain available; none is a quota. Prefer a supplied genuine screenshot over an invented mockup when claiming product behavior.

For source-timed graphics, derive local frame from `useCurrentFrame()`, use the actual composition FPS and keep source timestamps separate from Sequence-local frames. Bake physics once; replay by frame index. Use seeded randomness. Put local and parent transforms on separate wrappers. Text being read stays still. Render independent aspect-ratio layouts and check complete final composites.

Use `MasterTrack` for one long overlay when that simplifies placement, or explicit clips when requested. At an opaque butt cut, both beat fades are zero and the backdrop is opaque from frame zero. Check every frame around a transition, not only one exact boundary. Render ProRes4444 with PNG frames and the alpha pixel format, then strip unneeded audio; verify alpha and actual target-editor import.

`tools/flow_sfx.py` makes the original deterministic UI SFX. Feed it events derived from surviving visible scene anchors. No SFX on deleted graphics, no full music/song layering to imitate a vague preference, and no automatic enhancement of already-finished audio. Keep a selected music track; optional new generation requires an available licensed tool and explicit authorization. Historical music-generator weights are not bundled; the selected track is customer-owned input.

Run the disposable render and pure behavior tests before production. Technical checks support, but cannot replace, visual and listening review. Preserve original sources and output versions.
