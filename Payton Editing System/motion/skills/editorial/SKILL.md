# Editorial

The palette starts warm off-white `#F2F0EF`, deep green `#0F583D`, charcoal text and restrained mint highlights. Use large italic Instrument Serif for a meaningful phrase, clean smaller supporting text and thin diagrams. One idea at a time, no repeated headline at both top and bottom.

Keep sentence flow natural. Change sides with the argument rather than alternating mechanically. Preserve a single coordinate system for text, highlights and diagram attachments, especially during transitions. Inspect fully settled glyphs, ascenders/descenders, italic overshoot, masks and animation endpoints. Transparent and opaque states must intentionally match the source/presenter cut.

Recompose screen proof and presenter panels separately for landscape and portrait; reserve enough room for real UI labels and captions. A phone frame cannot rescue unreadable desktop text.
