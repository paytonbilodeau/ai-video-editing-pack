# Portable HyperFrames contract

The current customer request and `Vibe Editor Settings/EDITING PROFILE.md` govern this upstream bundle. Use the reviewed working copy and `node motion/hyperframes/run.mjs ...`, or the correct relative path to that wrapper from the project folder. It pins the runtime and disables telemetry/automatic skill refresh. Do not refresh to latest or install every provider as a routine setup step.

Reuse a working editor/engine when it fits. HyperFrames is HTML/GSAP; Flow remains the source of its actual Remotion components and Gentlemen pen implementation. Rendered assets can be reused after checking them, but source contracts are not interchangeable. The actual templates demonstrate landscape/portrait and an alpha route; customer media must replace any explicit media slot.

Upstream workflows describe available actions, not standing permission. Before any upload, remote generation, provider charge, publication, account creation, issue/feedback submission or external message, require authorization for that action. Preserve already-given authority and avoid duplicate questions. Never read unrelated files or credentials. Optional providers and models are not setup prerequisites. Native image generation and supplied audio are the default; final audio is handled once by the editing route.

Build with local media, fonts and scripts, one paused seekable timeline and framework-owned media playback. Keep the root canvas static and animate inner wrappers. Register after construction. Check direct out-of-order seeks, frame zero, joins and settled reading states. Do not add idle motion to satisfy a liveness checker. Inspect the doctor payload: optional Docker/Whisper/TTS/music tools can be absent while required Node, FFmpeg and Chrome work.

Run `check --snapshots`, then strict local render with the matching project frame rate. Use one worker for repeated pixel checks; cross-machine byte identity is not promised. MP4 is opaque. MOV alpha still requires decoded partial/blank/opaque samples, video-only streams and actual target-editor import. A successful browser preview is not a verified native timeline.

The library contains optional design/workflow capabilities beyond the current edit. Open only the required skill. Some source SFX/textures have explicitly labeled lawful procedural replacements. Do not mistake those for recordings from Payton's videos or for evidence of real products.
