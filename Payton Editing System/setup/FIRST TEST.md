# Make one small edit before using real work

![Keep both the editable project and the exported video, then check that the saved files open correctly.](<../../Kit Email Workflow/visual-guide/assets/07-project-and-export.png>)

Use a disposable project and the included `Practice/synthetic-lamp/` material at the full bundle root. Read [the practice instructions](<../../Practice/synthetic-lamp/START HERE.md>) before using the actual files. It uses synthetic pictures and a generated click, with no speech. A 10–20 second user-supplied clip is an optional next test. Keep its original bytes. This test checks the selected setup; it does not certify every editor operation or judge the complete house style.

1. **Read and explain the clip.** Identify its actual duration, frame rate, dimensions and audio. Name one complete action or sentence to keep, and one unneeded wait to remove. Do not infer words from a filename or a synthetic tone.
2. **Build an editable cut.** Import a copy into a new project or timeline through the supported native/interchange route. Keep complete words and the useful action. Save the native project and reopen it. Check source references and the actual cut boundaries.
3. **Make a short export.** Preserve the source frame rate and intended shape unless the brief asks otherwise. Decode the output and check duration, picture, sound and sync. Watch and listen to the exact join where available; report any unavailable perceptual check.
4. **Show the result and one useful choice.** Show the saved project, export and a simple before/after explanation. Ask whether to keep the starting pace and style or change a specific preference. Save only the accepted recurring change in the customer profile.

The basic test deliberately leaves motion and paid audio unactivated. If the first requested job needs either, add one small test of that selected route: render a supplied graphic and inspect its entrance/hold/exit, or review the authorized audio sample without processing the same sound twice. A render pass is technical evidence, not proof the design or sound is good.

If the assistant can create an interchange file but cannot operate the installed editor, name the exact import and save/reopen step for the user. Mark native import **unverified** until that step is actually observed. Do not silently substitute a flattened video for an editable project.
