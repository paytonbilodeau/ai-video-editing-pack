# Start with Payton's editing system

**Open the complete Vibe Editors folder in Codex or Claude Code. Then paste the setup message below.**

![The AI assistant reads a project folder and uses the video editor to produce an editable project and a review export.](<../../Kit Email Workflow/visual-guide/assets/01-workspace-map.png>)

## Setup message

> Set up this editing system for my videos. Read `Payton Editing System/setup/SKILL.md`, find the full bundle manifest, and reuse the tools and preferences already available. Create a separate working copy and use my existing editing profile if there is one. Otherwise, copy the included Payton-derived profile so it can be changed without touching the original. Ask only about choices that affect the first test. Run a short disposable edit from `Practice/synthetic-lamp/` through the available editor route, then show the saved project and export, what was checked, and any step that still needs a manual action. Name the downloaded source folder, the working workspace, the active profile and the loaded skill path. Tell me which folder to open for my next edit. Do not publish anything or connect a paid service without my choice.

The assistant will check what works on your computer, help with any missing access, and make a small test before touching your real video. No footage is needed to read the setup; the included lamp practice supplies the first editing test.

**Keep the starting look or change it.** The included profile supplies Payton-derived pacing, visual styles and review habits. Your own saved choices take priority. Adjust a color, font, caption style or pace after seeing the first test. There is no long questionnaire to finish first.

**The whole system is included.** Editing, sound, color, captions, motion, reviews and delivery are available when needed. The assistant opens the relevant module rather than installing every tool. [See what is inside](CONTENTS.md).

After setup, open the **editing workspace root** named in the readback, which contains the installed project skills and `Vibe Editor Pack/`. Ask for the edit you want. Your editable profile lives outside the pack so updates can preserve it. [Update an existing installation](UPDATES.md).

If the assistant cannot read local files, use Codex or Claude Code in a local project, or follow [the manual setup route](<APP SETUP.md>). A chat attachment alone cannot operate your editor.
