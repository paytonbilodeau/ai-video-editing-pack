# Source and portability

This component adapts Payton's own editing instructions, code and configuration with his authorization. It preserves the operational methods and typed starting preferences while removing private project/account bindings. The release's private provenance record maps original hashes to portable hashes; it is not distributed because it points to private working sources.

No original footage, creator portrait, customer file, account cache, API key, paid course text, proprietary plugin, model weight or third-party font is included in this editing component. External applications and optional libraries retain their own licenses and installation terms. The sibling motion component includes its own asset/license inventory; the base public pack includes its original license.

Source history is not a universal performance claim. Native operations have tested scope and version limits; microphone settings are audition starts; accepted aesthetic examples do not certify a camera transform. Existing user customizations and current project instructions take priority.

No private service, machine or source path is needed to use these portable files. Future revisions are separately reviewed and released; no automatic connection to the author's system is created.
