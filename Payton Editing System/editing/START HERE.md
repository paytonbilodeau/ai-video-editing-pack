# Start with Payton's editing system

Open the complete bundle's setup guide first. It copies this starting profile into your own settings folder, keeps existing customizations and checks the editor route you actually use.

```text
Read this editing system and my existing editing profile. Use Payton's starting choices only where I have not already made a choice. Keep my original footage and editable projects. Check the tools I already have, then run one disposable test of the route this edit needs. Ask only about consequential differences: output, editing style, microphone, captions and optional cloud audio. Tell me what worked, what needs a manual step and the simplest next action.
```

Once setup is ready, give the assistant one recording and the result you want. No need to fill every template yourself. The assistant should complete the relevant records from the supplied material.

**What is included:** the [prefilled editing profile](profiles/PAYTON%20EDITING%20PROFILE.md), [editing workflow](SKILL.md), four microphone procedures, source/transcript and cut tools, native Resolve controls, saved keyboard/layout/export configurations, captions and short extraction, protected audio restoration and final-file checks. The [tool guide](references/TOOLS.md) names the dependencies and exact capabilities. The full bundle's original editing pack supplies other-editor playbooks and timeline interchange.

Start with a short disposable sample, then your actual recording. A successful test establishes that operation on that setup. It does not mean the assistant has watched a full video, matched your taste or tested every editor.

For the full content map, open [CONTENTS](CONTENTS.md). The ordinary workflow needs only the current phase; the rest remains available when the recording calls for it.
