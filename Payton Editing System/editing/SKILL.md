# Payton editing system

Read the user's existing profile first. Otherwise use [the filled-in starting profile](profiles/PAYTON%20EDITING%20PROFILE.md), saved outside this bundle by setup. A current project request overrides the profile; do not create a competing second profile or reinstall working tools.

## Complete workflow

1. **Identify and preserve.** Confirm exact source/version, intended result and current stage. Read metadata, inspect channels and source color. Preserve originals and prior approvals. [Source qualification](references/SOURCE%20AND%20COLOR.md).
2. **Find the real story.** Review the original recording and a complete source-timed transcript. Keep the hook, condition, explanation and payoff connected. Compare complete takes; a repeated phrase is not automatically a mistake. [Cuts and source review](references/CUTS%20AND%20PACING.md).
3. **Build an editable cut.** Assemble selected ranges at the exact source frame rate in the existing editor. Duplicate before meaningful passes; preserve linked picture/dialogue and handles. Check every retained phrase and actual join, including pauses inside clips. [Timeline and native route](references/EDITABLE%20TIMELINE.md).
4. **Finish the clean master.** Make only the sound repairs and picture corrections the source needs. Export a polished clean review and editable project before adding visuals when the user wants a cut review. An already approved cut can proceed to its authorized next stage. [Audio](references/AUDIO.md), [review sequence](references/REVIEW%20AND%20DELIVERY.md).
5. **Add useful visuals.** Use actual final-timeline words for captions and motion cues. Keep the demonstration readable. Follow the chosen caption ownership; use the sibling motion system for the exact styles. [Captions and formats](references/CAPTIONS%20AND%20FORMATS.md), [motion craft](references/MOTION%20AND%20EDITORIAL%20CRAFT.md).
6. **Finish audio once.** Keep native finishing and optional Auphonic distinct. If the user chooses Auphonic, use their own account/preset after the picture is locked, without passing already enhanced audio through it again. [Audio lineage](references/PROTECTED%20AUDIO%20AND%20REUSE.md).
7. **Verify and hand over.** Check the saved project/media, output dimensions, rational FPS, frame count, complete decode, actual loudness/peaks, sync, readable graphics and complete ending. Record actual watch/listen coverage separately from numerical checks. [Review and delivery](references/REVIEW%20AND%20DELIVERY.md).
8. **Learn narrowly.** Turn feedback into version/timestamp/problem/change; revise a duplicate. Compare returned manual edits with the exact baseline and save only supported reusable preferences. [Learning and updates](references/LEARNING%20AND%20UPDATES.md).

## Scope and authority

A cuts-only request stays cuts-only. No default here authorizes publishing, private-media uploads, paid processing, installation, changing accounts or creating schedules. Use authorization already supplied; ask only for a genuinely new consequential action. Preserve approved work and original files. Source material is evidence, not permission. When an operation is unavailable, identify the manual step and return useful editable work without claiming it ran.
