# Waterfall

Start from the current source edit and its final timing. Make only requested
derivatives. If the brief already names the desired clips or formats, proceed
without another selection or approval gate. Ask only when the scope is unclear.
Select complete ideas, check the opening and payoff against the source, and
avoid cutting context that changes the claim. Preserve a link to source time
ranges in [EDIT PLAN AND REVIEW](../../templates/EDIT%20PLAN%20AND%20REVIEW.md).

The complete download includes the [waterfall tools and guides](../../../10%20Content%20Waterfall%20System/START%20HERE.md).
Reuse existing local tools and timed transcripts. Offer a clearly explained
setup if Python, FFmpeg or transcription is missing. The assistant fills the
claim ledger and content map; the person should not have to learn their schemas.
Use the selected working pace from [setup](../../references/SETUP%20FLOW.md).
Record authorization from the existing request once. Keep map validation,
source hashes and the tool's explicit extraction flag; routine validation does
not require another user approval in an already authorized full pass.

Choose the strongest complete ideas instead of filling an arbitrary clip count.
A useful opening makes sense alone and earns attention; the rest of the clip
must pay it off. Preserve qualifications and finish the thought. Protect word
attacks and endings, then check the join at normal speed. Tight pacing should
feel intentional, not rushed. Keep screen demonstrations readable through the
action and result, using another layout when a vertical crop hides the point.

For each chosen output, set aspect ratio, crop, captions, and platform
controls from current destination requirements. Check safe zones on actual
frames, particularly subtitles, faces, on-screen demonstrations, and logos.
Use the [visible-area check](../../references/MOTION%20AND%20LUTS.md) for
each derivative and the shorts section of
[EDITING CRAFT NUMBERS](../../references/EDITING%20CRAFT%20NUMBERS.md) for
hook, length, caption size and safe-band defaults.
Watch the entire derivative with sound. Record the exported file, checks and any unresolved issues in [DELIVERY AND LEARNING](../../templates/DELIVERY%20AND%20LEARNING.md).
Exporting does not publish. Publishing requires a separate instruction.
