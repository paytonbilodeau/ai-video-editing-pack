# Update Your Pack Without Losing Your Setup

Download and extract the [latest complete pack](https://github.com/paytonbilodeau/ai-video-editing-pack/releases/latest/download/ai-video-editing-pack.zip)
beside your existing copy. Keep the old folder until the new one works. Give both
folders to your AI and paste this:

```text
Update my AI video editing setup using this new Vibe Editors folder. Read its
START HERE and AI Video Editing Pack/SKILL.md. Compare it with my existing pack,
skills, project instructions and editing profile before changing anything.

Keep my taste, branding, custom skills, footage and current projects. Keep my
private profile outside the pack. If it is currently inside the old pack, copy
it to a separate private location and verify that copy before changing pointers.

Tell me the useful changes briefly. Apply compatible improvements at my chosen
pace: careful, balanced, or handle it for me. Reuse my existing decisions and
permissions. Explain conflicts or new access, uploads and costs before using
them unless already authorized. Do not overwrite my custom instructions with
the new defaults.

Keep a recoverable copy of anything you change. Check the new tools and links,
then update the project pointers to the working version. Preserve the old setup
until the new one is verified. Finish with what changed, what was tested, any
remaining manual step, and where my profile and rollback copy live.
```

## What your AI should do

1. Find the old pack, project instructions and private profile inside the folders
   you provide. Reuse an existing installation instead of creating competing
   copies. Do not search the rest of the computer without a reason and access.
2. Compare versions and customizations. A newer file is not automatically a better
   instruction for your workflow. Preserve local choices and explain conflicts.
3. Keep the new complete folder together. The pre-edit, motion, waterfall and
   reader-guide folders are part of the download. Copying only the core skill
   folder leaves those supporting files behind.
4. Check tools in an isolated or disposable location where possible. Use existing
   runtimes when compatible. Install missing dependencies only for the routes
   you choose; explain their source, access and cost.
5. Change the relevant project pointer after checking that the new path exists
   and the required route works. Preserve unrelated AGENTS.md or CLAUDE.md
   instructions. A successful file copy alone does not prove an editor connection.
6. Keep a short record of old and new paths so the previous setup can be restored.
   Ask before removing the old folder or anything that may contain personal work.

Your ongoing projects do not need to migrate in the middle of an edit. Finish
with the version that works, or test the update on a duplicate project first.

Native plugin updates refresh the core skills. For the complete set of supporting
tools and all 22 illustrated lessons, use the full ZIP linked above. Your AI can
help connect that folder to the plugin without replacing your private profile.
