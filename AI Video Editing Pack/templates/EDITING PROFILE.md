When the user gives a clear reusable correction, save it with its context.
For example, “Leave the result on screen long enough to read it” is more useful
than “slow down.” If a choice might apply to only one video, clarify before
making it a general rule. Keep the previous profile version recoverable.
Check the rule during later suitable work; do not assign the user a practice
clip. Record observed results separately from intended improvements.

Keep private media and references private. Never store passwords, tokens or
API keys here. Saved preferences guide the AI when read; they do not train a
model or guarantee that every future chat remembers them.
