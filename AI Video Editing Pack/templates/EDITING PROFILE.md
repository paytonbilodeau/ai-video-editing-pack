# Reusable Editing Profile

Keep a private copy in one stable folder across projects. It contains only
preferences the editor has accepted and examples they have permission to
retain. Do not place client footage, private references, or personal settings
in the public pack. Keep the previous profile version before changing a rule.
Do not store API keys, passwords or tokens in this profile. Record only the
service name and private secret-storage location when a connection needs one.

## Update from a reviewed correction

1. Preserve the previous project and profile version.
2. Compare the actual changed source ranges; ask the editor why if unclear.
3. Decide whether this was a one-video choice, a general defect fix, or a
   preference to reuse. Enter only an accepted reusable preference above.
4. Test it on another suitable clip, record the observed result, and revise
   or remove the rule if it harms that edit.

This is saved context for an assistant, not model training or a guarantee.
