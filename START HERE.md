# Turn AI into your video editor

**[8-step visual walkthrough](Kit%20Email%20Workflow/visual-guide/README.md)**

Download and unzip the pack. In Codex, start a **Local** task in a dedicated
editing folder, then select the extracted **Vibe Editors** folder or give its
exact location. Ask the AI to list a few files it can read, then paste the
message below. The [AI app setup guide](AI%20Video%20Editing%20Pack/references/AI%20APP%20SETUP.md)
also covers Claude Code. No recording is needed yet.

Already have an editor, skills or a workflow? Keep them. The pack should connect
to what you use and fill the gaps. The whole free system is here, including the
tools and teaching guide. You don't need to wait for the emails.

```text
Set up this Vibe Editors folder so you can be my video editor. Read its START HERE guide and follow the setup skill. Ask how hands-on I want to be: careful, balanced, or handle it for me. Reuse my existing tools, permissions, skills and preferences. Keep my originals and projects safe, and keep my private editing profile outside the pack. Explain any new access, upload, installation or cost before using it unless already authorized. Offer useful optional tools, then set up what fits. List a few files you can read in this pack, show where my private editing profile is saved, and separate editor actions you tested from actions that still need me. Tell me the simplest next step. No footage is needed for setup.
```

## What happens next

Your AI checks the tools it can already use, helps connect your editor, and
saves your preferences privately. If something needs your click, it explains
the exact choice and why it matters. It should distinguish a tested connection
from a route it has only read about. Ask it to show the profile path and name
any editor actions that still need you. Readable files do not by themselves
prove the editor is connected.

Then give it a recording and say what you want: a clean cut, a complete video,
motion graphics, or clips from a longer recording. It uses the parts this job
needs. You review the result and keep creative control.

For your first edit, follow the [8-step visual walkthrough](Kit%20Email%20Workflow/visual-guide/README.md).
LUTs, motion tools and repurposing are optional.
